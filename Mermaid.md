## Mermaid

**Mermaid** - это сильно упрощённый и далекий аналог
**UML** - специальный язык описания блок-схем, графиков и диаграмм с их визуализацией.

>**Самостоятельно доделать этот README**

### Блок схемы

#### Базованя структура 1
```mermaid
flowchart LR
    A[Вопрос: Как сдеать список?] --> B["Ответ: - `-` или `*`"]
    A --> C["Пример: \n - Пункт 1 \n"]
```
* `flowchart` - блок-схема
* `LR` - направление вправо
* `A[],B[],C[]` - прямоугольник
* `-->` - стрелка связи
#### Базовая структура 2
```mermaid
flowchart TD
    Start((Начало)) --> Step1[Шаг 1]
    Step1 --> Decision{Условие?}
    Decision -->|Да| Step2[Шаг 2]
    Decision -->|Нет| End((Конец))
    Step2 --> End
```


* `TD` — направление сверху вниз (Top-Down), другие варианты: `BT`, `LR`, `RL`
* `(( ))` — круг/точка старта-конца
* `{ }` — ромб (условие/решение)
* `-->|текст|` — подпись на стрелке

### Полный синтаксис блок-схем
**Формы узлов:**
```mermaid
flowchart LR
    A[Прямоугольник]
    B(Скруглённый)
    C([Стадион])
    D[[Подпрограмма]]
    E[(База данных)]
    F((Круг))
    G{Ромб}
    H{{Шестиугольник}}
    I[/Параллелограмм/]
    J[\Параллелограмм 2\]
```

**Типы стрелок:**
```mermaid
flowchart LR
    A --> B
    A --- C
    A -.-> D
    A ==> E
    A -->|подпись| F
    A -.подпись.-> G
    A ==подпись==> H
```
**Подграфы (subgraph):**
```mermaid
flowchart TB
    subgraph one["Группа 1"]
    a1 --> a2
    end
    subgraph two["Группа 2"]
    b1 --> b2
    end
    one --> two
```

### Диаграмма посладовательности
```mermaid
sequenceDiagram
    participant U as Пользователь
    participant S as Сервер
    U->>S: Запрос данных
    activate S
    S-->>U: Ответ (200 OK)
    deactivate S
    Note over U,S: Обмен завершён
    alt Ошибка
        S-->>U: 500 Error
    else Успех
        S-->>U: Данные
    end
```
* `->>` — сплошная стрелка с запросом
* `-->>` — пунктирная стрелка (ответ)
* `activate`/`deactivate` — жизненная линия
* `alt/else/end` — условные ветки
* `loop`, `par`, `Note` — доп. блоки

### Диаграмма класса
```mermaid
classDiagram
    class Animal {
        +String name
        +int age
        +makeSound() void
    }
    class Dog {
        +fetch() void
    }
    Animal <|-- Dog : наследование
    Animal *-- Heart : композиция
    Animal o-- Owner : агрегация
```
* `<|--` наследование, `*--` композиция, `o--` агрегация, `-->` ассоциация
* `+`/`-`/`#` — public/private/protected

### Граф зависимостей
```mermaid
flowchart TD
    App[Приложение] --> LibA[Библиотека A]
    App --> LibB[Библиотека B]
    LibA --> LibC[Общая утилита]
    LibB --> LibC
```
Обычно используется `flowchart` с направлением `TD`, где узлы — модули/пакеты, а рёбра — зависимости "использует".

### Диаграмма состояний
```mermaid
stateDiagram-v2
    [*] --> Черновик
    Черновик --> НаПроверке: отправить
    НаПроверке --> Опубликовано: одобрить
    НаПроверке --> Черновик: отклонить
    Опубликовано --> [*]
```
* `[*]` — начальное/конечное состояние
* `state "Описание" as X` — псевдонимы
* Можно вкладывать составные состояния через `state X { ... }`

### Юзер-джайрни
```mermaid
journey
    title Покупка товара
    section Поиск
      Открыть сайт: 5: Пользователь
      Найти товар: 3: Пользователь
    section Оформление
      Добавить в корзину: 4: Пользователь
      Оплатить: 2: Пользователь
```
Числа (1–5) — уровень удовлетворённости на каждом шаге.

### Кастомизация стилей
```mermaid
flowchart LR
    A[Важно] --> B[Обычно]
    style A fill:#f96,stroke:#333,stroke-width:2px
    style B fill:#9f9,stroke:#333
```
Также можно задать глобальную тему через `%%{init: {'theme':'dark'}}%%` в начале диаграммы.

---
#### Классы CSS
```mermaid
flowchart LR
    A[Узел 1]:::warn --> B[Узел 2]:::ok
    classDef warn fill:#f96,stroke:#900,color:#fff
    classDef ok fill:#9f9,stroke:#090
```
`classDef` создаёт именованный стиль, `:::имя` применяет его к узлу — удобно для повторного использования.

---
#### Интерактивность

```mermaid
flowchart LR
    A[Кликни] --> B[Ссылка]
    click A callback "Подсказка"
    click B "https://example.com" "Открыть сайт"
```
* `click узел callback` — вызов JS-функции
* `click узел "URL"` — переход по ссылке
* Работает только на площадках, где включён `securityLevel: loose`
