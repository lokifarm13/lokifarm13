## Bash

Bash - это консоль (CLI) и скриптовый язык програмирования

### Упраление Терминалом (консолью)

Сдвинуть лог вверх
`Ctrl+L`

Очистить экран
`clear`

Получить историю
```shell
history
```

Перелистывание ранее введёный команд
`Стрелка вверх/Стрелка вниз`

Выполнить последнюю (из списка history) команду
```shell
!!
```
Выполнить указанную команду из списка history
```shell
!45
```
где `45` это порядковый № комнады из history

Остановить запущенный в консоле процесс по `Ctrl+C`

### Файловые операции

Получить сктруктуру каталогов и файлов
```shell
tree
```
получить абсолютный путь к текущему каталогу
```shell
pwd
```
показать содержимое текущего каталога
```shell
ls
```
или подробно
```shell
ll
```
или
```shell
ls -all
```
или показать содержимое указанной папки
```shell
ls Dir_name
```
где `Dir_name` - это имя нужной папки

Правильно именования каталогов файлов:
1. Только по-английски
1. Без пробелов и спец.символов
1. Если имя файла или каталога состоит из нескольких английских слов., то имя можно создать так: `firstOfall` или `firts_of_all`
1. В имени файлов лучше всегда указывать расширение `fileName.txt`

Выйти из текущей папки
```shell
cd ..
```
Вернуться в предыдущую папку
```shell
cd -
```
Зайди в указанную папку
```shell
cd TargetFolder
```

Знаки:
`\` - обратный слэш - признак каталога
`/` - прямой слэш - признак каталога
`|` - вертикальный слэш - признак разделения команд

Windows
`\` - корневой каталог
Unix/Linux/Android,macOS,iOs,BSD:
`/` - корневой каталог

Выйти из текущего каталога на 2 шага вверх
```shell
cd ../..
```

#### Создание файлов и каталогов

Создание файлов
```shell
touch file_name.txt
```
редактировать текстовый файл
```shell
micro file_name.txt
```
- `micro` - текстовый редактор командной строки
- Сохранить по `Ctrl+S` и выйти из редактора по `Ctrl+Q`

Переименовать файл
```shell
mv old_name new_name
```
копирование файла
```shell
cp name_file.txt NewFolder/
```
переместить файл
```shell
mv file.txt TargetName
```
Удалить файл
```shell
rm delFile.txt
```
Удалить папку
```shell
rm -rf DelFolder
```
Создать несколько файлов
```shell
touch {1..3}.txt
```
Создать несколько каталогов
```shell
mkfir folderName{1..4}
```
Удалить содержимое текущего
```shell
rm rf *
```
Создать структуру проекта:
```
project/
├── css/
├── js/
├── img/
│   └── ico/
├── fonts/
└── pages/
```
Создать такую структуру одной командой
```shell
mkdir -p project/{css,js,img/ico,fonts,pages}
```

### Linux

```shell
hostname
```
Логальный ip
```shell
hostname -i
```

сетевая информация
```shell
ifconfing
```
или
```shell
ip -c r
```
или подробно
```shell
ip -c a
```
Пинг
```shell
ping ya.ru
```
или определённое кол-во раз
```shell
ping -c 4 ya.ru
```
Получить ин-фу по домену
```shell
whois ozon.ru
```
Получить порты
```shell
netstat -an
```
Получить маршруты
```shell
route
```
Выйти из сеанса пользователя
```shell
exit
```
Перезагрузить
```shell
reboot
```

```shell

```
Показать текущее время
```shell
date
```

календарь

или
