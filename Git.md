## Основы Git

### Зачем Git?

#### Почему не флешка?


1. Флешка - потенциальный разносчик вирусов
1. Ваши личные данные могут случайно попасть на чужой компьютер
1. Антивирус может удалить ваши файлы с флешки
1. Флешка может потеряться или сломаться

#### Почему не Yandex или Google диск?

1. Облако Yandex или Google не контролирует версии файлов
1. Ваши данные к Yandex или Google могут случайно остаться на чужом комьютере

### Преимущества Git

1. Трудно потерять свои проекты
1. Легко отслеживать версии ваших проектов
1. Легко делиться с другими людьми вашими проектами
1. Легко вести совместную работу над одним проектом
1. Git - де-факто стандарт в IT и интегрирован почти во все современные технологии IT (например в VS Code etc.).
1. В Git можно создавать веб-страницы как хостинге
1. Git-сервисы дают возможность автоматизировать сборки и тестирование ваших приложений.

### Основные состояния Git-репозитория

1. **Инициализация** - `git status` - показывает текущее состояние репозитория
1. **Подготовка** - `git add .` - подготовка (добавление) изменений
1. **Фиксация** - `git commit -m 'Some message'`
1. **Синхронизация** - удалённой копией текущего репозитория - `git push` и `git pull`

### Что можно сохрнять в git?

1. Любые текстовые файлы, объёмом <= ~ 40 mb.
1. Изображения, документы, mp3, PDF, короткие видео т.п.
1. Все имена файлов и каталогов только по-английски без пробелов и спец. символова!

### Основные команды Git

Получить версию установленного Git
```shell
git version
```
или
```shell
git --version
```
Получить справку
```shell
git help
```
**Сменить текстовый редактор по умолчанию**
На `Micro` (проще для новичков)
```shell
git config --global core.editor "micro"
```
На `Nano` (чуть сложнее для новичков)
```shell
git config --global core.editor "nano"
```
На `Micro` (элементарен для новичков)
```shell
git config --global core.editor "code --wait"
```
**Представиться системе Git**
Сообщить свой никнэйм
```shell
git config --global user.name "Fixic"
```
Сообщить свой эмэйл
```shell
git config --global user.email "my_email@mail.ru"
```

>**Если вы на чужом компьютере, то вместо `--global` используйте `--local`**

#### Клонирование репозетория

```shell
git clone http://gitflick.ru/project/lokifarm13/lokifarm13.git
```
открыть папку клонированного репозитория
```shell
cd folder_name
```
Получить статус текущего репозитория
```shell
git status
```
Получить состояние удалённого репозитория
```shell
git remote show origin
```
```
git branch
```
```shell
git branch --v
```
Получить лог удалённыъ веток
```shell
git remote --v
```
Выйти из режима логов по клавише `Q`.

Получить общий лог
```shell
git log
```
Выйти из режима логов по клавише `Q`.

Получить лог изменений с указанием кол-ва последних коммитов
```shell
git log -p
```
Выйти из режима логов по клавише `Q`.

Получить хэши и их коммиты
```shell
git log --oneline
```

После внесения изменений (модификаций) можно подготовить и закоммитить результат
```shell
git add .
```
и
```shell
git commit -m 'Any changes'
```
чтобы изменить текст последнего коммита
```shell
git commit --amend
```
